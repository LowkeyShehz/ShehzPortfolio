# Shehzan's Portfolio

A modern, dynamic portfolio website showcasing projects in Apps, Games, and Web development.

## Shehz Studios
The portfolio also presents **Shehz Studios**, an AI-native indie game studio (name is a placeholder) building stylized low poly multiplayer games. The `#studio` section covers the studio's mission, its first title (a multiplayer zombie apocalypse game, currently in pre-production), a roadmap, and how AI is used in development.

## Features
- **Dynamic Project Hero**: Interactive CardSwap component synced with a featured info panel.
- **Projects Carousel**: Explore additional projects through a smooth horizontal carousel.
- **Project Details**: Dedicated pages for each project with detailed descriptions and image galleries.
- **Studio Section**: Company overview, flagship game, roadmap and AI workflow.
- **Responsive Design**: Optimized for both desktop and mobile viewports.
- **Modern Tech Stack**: Built with HTML, CSS, JavaScript, and GSAP for high-quality animations.

## Projects Featured
- **VTU CGPA Calculator**: A comprehensive tool for VTU students with auto-fetch and OCR capabilities.
- **VectorProtocol**: Tactical self-development tracking app.
- **Action RPG**: Unity-based 3rd-person RPG prototype.
- **AR History App**: Educational AR experience for exploring historical monuments.
- **Adhkar**: Spiritual reflection and daily Adhkar app.
- **Hytale Portfolio**: Themed landing page for the Hytale community.

## Development
This is a vanilla web project using:
- **GSAP** for animations.
- **Phosphor Icons** for iconography.
- **Google Fonts (Outfit)** for typography.
